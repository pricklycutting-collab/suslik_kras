# Суслики — хранители Красноярска

Мобильный прототип уютного семейного квеста по 24 бронзовым скульптурам. Координаты и названия предоставлены автором проекта; точки не проверены на местности.

## Запуск

Скачайте репозиторий или выполните `git clone https://github.com/pricklycutting-collab/suslik_kras.git`, затем `cd suslik_kras` и `npm start` (Node.js/npm и Python 3, порт 3000). На своём компьютере откройте `http://localhost:3000`. Установка зависимостей и сборка не нужны. Для разработки модулей открывайте приложение через HTTP, а не как файл. Для камеры на телефоне при размещении приложения нужен HTTPS; доступен также выбор изображения. Интерфейс использует системный выбор фото/камеры, поведение зависит от браузера.

`npm test` проверяет каталог, координаты навигационных ссылок и расчёт прогресса.

## Возможности и ограничения

Поиск и фильтры коллекции, карточки точек, переход в Яндекс Карты, фотоотметки и финал после всех 24 встреч. Снимки уменьшаются до 1200 пикселей и сохраняются с прогрессом в IndexedDB текущего браузера. Геолокация не проверяется. Аккаунтов, сервера, синхронизации и экспорта пока нет: очистка браузера удаляет коллекцию. Исходные фотографии скульптур пока не добавлены как файлы; иллюстрации в карточках — временные эмодзи, декоративный пейзаж выполнен CSS. Исторические справки и культурные сюжеты требуют подготовки и проверки источников. Внешний шрифт необязателен, есть системный запасной вариант.
