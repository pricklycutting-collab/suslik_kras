# Суслики — хранители Красноярска

MVP мобильного семейного квеста по 24 бронзовым скульптурам. Выберите суслика на полноэкранной игровой карте Красноярска, поговорите с хранителем, найдите настоящую статую, выполните задание и сохраните фото — туман рассеется, а персонаж вспомнит свою историю.

## Что работает

- Название команды и вступительный диалог: Чтец просит помощи, Забывайка раскрывает свою затею, игрок выбирает ответ. Завязку можно повторить с главного экрана.
- Полноэкранная пиксельная карта с Енисеем, мостами, городскими кварталами, лесными хребтами и островами по предоставленному визуальному референсу. Суслики стоят прямо в мире, без отдельной сетки точек. Карту можно двигать пальцем, мышью или клавишами и приближать кнопками. Спасённые персонажи отмечаются золотой звездой.
- Игровое меню поверх карты: «Карта», «Суслики», «Старт», счётчик спасённых, масштабирование и кнопка альбома. Коллекция, альбом и награды открываются отдельными панелями; лендинговая компоновка удалена.
- Локальный пиксельный шрифт Press Start 2P (лицензия OFL в `assets/fonts`), рамки и таблички в стиле ретро-RPG.
- На карте используется общий маленький спрайт суслика; индивидуальные эскизы всех 24 персонажей остаются в карточках и диалогах. Карточки, поиск и фильтры доступны через кнопку «Суслики». У каждого — своя проблема, выбор реплики, задание и отдельный разговор после спасения. В карточке можно поговорить повторно; разговор можно пропустить.
- 24 отдельных задания для семей; перед фотоотметкой игрок подтверждает выполнение.
- Подборки точек и переходы в Яндекс Карты и 2ГИС. Это подборки, не проверенные пешеходные маршруты.
- Награды после любых 5, 12 и 24 встреч. На каждом этапе Забывайка отвечает игроку; в финале перестаёт прятать город и становится добрым облаком.
- Предпросмотр, уменьшение и сохранение фото, замена снимка и удаление встречи с подтверждением.
- Семейный фотоальбом, скачивание резервной копии и восстановление с проверкой файла. Восстановление дополняет коллекцию и заменяет совпадающие снимки после подтверждения.
- Офлайн-режим после полной первой загрузки и установка на главный экран при размещении через HTTPS.

Аккаунтов, сервера, аналитики и GPS-проверки нет. Снимки не отправляются на сервер. Культура города отражена в художественном сюжете и заданиях на наблюдение; проверенные исторические справки и пешеходные маршруты ещё не подготовлены. Координаты предоставлены автором проекта, проверка на местности не проводилась. Положение точек на панораме художественное: оно не совпадает с реальной картой, которая открывается отдельно из карточки. Сюжет и реплики — вымысел, не исторические цитаты. Иллюстрации стилизованы по фото, часть деталей художественно интерпретирована.

## Опубликовать и открыть на телефоне

Публичный сайт не появляется от одной загрузки файлов на GitHub. Репозиторий содержит готовый workflow публикации.

1. На GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Откройте **Actions → Publish game to GitHub Pages → Run workflow**, выберите `main` и запустите.
3. После успешного выполнения откройте адрес, показанный в **Settings → Pages** или в результате шага **Deploy**. Проверьте, что опубликован последний коммит.
4. Откройте эту HTTPS-ссылку на телефоне. В Safari используйте **Поделиться → На экран Домой**, в Chrome — **Установить приложение** или **Добавить на главный экран**.

Для каждого обновления повторите запуск workflow. Он публикует только игровые файлы и изображения; исходные тесты и зависимости не попадают в артефакт сайта. GitHub Pages должен быть доступен для типа и тарифа репозитория; для закрытых репозиториев это зависит от плана GitHub. Если Pages недоступен, разместите те же статические файлы на другом HTTPS-хостинге.

## Запустить на своём компьютере

Нужны Python 3 и Node.js/npm:

```bash
git clone https://github.com/pricklycutting-collab/suslik_kras.git
cd suslik_kras
npm start
```

Откройте `http://localhost:3000` на этом же компьютере. Для запуска игры установка npm-зависимостей и сборка не нужны. HTML с модулями нужно открывать через сервер, а не двойным кликом по файлу.

Телефон в той же Wi-Fi сети может открыть `http://IP-компьютера:3000` при разрешённом доступе к порту. На обычном HTTP по адресу локальной сети офлайн-режим и установка PWA не работают: тестируйте их через HTTPS. Доступ к камере и выбор файлов зависят от браузера и ОС. Если HEIC не читается, выберите JPEG или PNG.

## Проверить MVP вручную

1. Назовите команду, пройдите вступительный диалог и выберите ответ Чтецу. На карте нажмите суслика, поговорите с хранителем и перейдите к месту встречи. Двигайте карту и используйте +/− для масштаба; поиск и подборки находятся в меню «Суслики», фото и копии — под кнопкой альбома. Счётчик открывает награды.
2. Выберите суслика. Попробуйте сохранить встречу без задания, затем без фото: должны появиться понятные подсказки.
3. Отметьте выполнение задания, добавьте снимок и сохраните. Хранитель поблагодарит команду; вернитесь в город и поговорите с ним повторно — теперь он помнит встречу. Перезагрузите страницу: фото, команда и прогресс должны остаться. Закрытие разговора до выполнения задания не спасает персонажа.
4. Найдите пять разных хранителей: появится первая награда и новая реплика Забывайки. Замена фото одного хранителя не увеличивает счётчик.
5. Скачайте копию альбома. Удалите одну встречу и восстановите копию: фото и прогресс вернутся. Отмена восстановления не меняет данные.
6. Дождитесь сообщения об офлайн-доступе, выключите сеть, перезагрузите игру и добавьте ещё одну встречу. Внешние карты без интернета не открываются.
7. Проверьте фото и установку на реальном iPhone/Android перед полевым запуском. Автоматические проверки выполнены в Chromium, включая мобильный размер экрана; физические телефоны не проверены.

## Автоматические проверки

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

11 модульных проверок: каталог, навигационные координаты, прогресс, награды, задания, валидация и перенос резервных копий, диалоги всех 24 героев, сюжетные этапы и отсутствие перекрывающихся персонажей на карте и расчёт размеров камеры. 9 браузерных сценариев: мобильный интерфейс, фотоотметки, сохранение и замена, первая победа, импорт/экспорт, офлайн-загрузка с подпапки, большой финал, сохранение прежних записей IndexedDB и отказ хранилища. Дополнительно проверяются выбор реплики, разговор до и после спасения, отмена, доступность всех 24 точек на телефоне и экран шириной 320 пикселей. Отдельный сценарий проверяет полноэкранную карту, масштабирование, перетаскивание, игровые панели и горизонтальную ориентацию.

При наличии `/usr/bin/chromium` тесты используют его автоматически. Можно указать другой исполняемый файл через `TEST_BROWSER_PATH`. Браузерные проверки запускают временный сервер на порту 3100 и используют отдельные профили, не затрагивая пользовательский альбом. GitHub Actions запускает проверки при push и pull request.

## Хранение и ограничения

Фото уменьшаются до 1200 пикселей и сохраняются как JPEG в IndexedDB браузера. При обновлении MVP прежние встречи из прототипа сохраняются. Смена устройства, домена, профиля или очистка данных браузера не переносит коллекцию автоматически. Сначала скачайте копию альбома, затем восстановите её в новом браузере. Файл копии содержит фотографии — храните его как личный альбом.

Первое офлайн-кэширование загружает около 15 МБ изображений и локальный шрифт. Дождитесь завершения с интернетом. Браузер может позже удалить локальное хранилище при нехватке места — резервная копия остаётся способом восстановления. При выпуске изменений обновляйте версию кэша в `sw.js`; service worker обновляет офлайн-файлы после успешной загрузки новой версии. Обновление уже открытой вкладки потребует перезагрузки.

## Структура

- `index.html`, `style.css`, `app.js` — интерфейс и игровые действия.
- `locations.js`, `game.js` — точки, задания, главы и проверка копий.
- `storage.js` — IndexedDB, атомарное восстановление и настройки команды.
- `city.js`, `sprites.js` — камера мира, интерактивные персонажи и отображение индивидуальных героев из исходных листов эскизов.
- `story.js`, `dialogue.js` — реплики, сюжетные этапы и интерфейс диалогов.
- `assets/krasnoyarsk-world.png` — художественный фон по визуальному референсу пользователя, не географическая карта.
- `assets/map-suslik.png` — общий прозрачный спрайт для персонажей на карте.
- `assets/concepts` — все шесть листов; исходные изображения не изменялись. Фотографии статуй из чата не включены как отдельные файлы.
- `manifest.webmanifest`, `sw.js` — установка и офлайн-режим.
- `.github/workflows` — проверки и ручная публикация.
