# Эскизы персонажей

Созданные концепты для всех 24 точек. MVP отображает отдельные области этих листов через CSS, сохраняя исходные файлы. Это стилизованные эскизы, а не точные копии скульптур или готовые анимационные спрайты.

- `01-adventurers.png`: покоритель Енисея, походник, разметчик, страж, строитель.
- `02-umbrella-medic-obrada-teacher.png`: с зонтиком, медик, Обрада, педагог.
- `03-inspector-klim-cosmonaut-cook.png`: инспектор, Клим, космонавт, поварёнок.
- `04-sail-it-sauna-vovchik-miner.png`: грек и суслик, айтишник, банщик, Вовчик, горняк Гоша.
- `05-wrestler.png`: борец.
- `06-football-coins-artist-reader-newlyweds.png`: футболист, хранитель монет, художник, чтец, молодожёны.

Исходные фотографии из чата не включены: в рабочей папке они не представлены отдельными файлами.
